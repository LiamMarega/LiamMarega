## Selected Work

### 📱 Ferox App

**Flutter Mobile Developer · 2023 — Present**

Production social platform with **60K+ downloads** across iOS and Android.

* Real-time feeds, follows, likes, reposts, comments and search
* Offline-tolerant messaging built around WebSockets
* Media uploads and vertical content experiences
* REST APIs, JWT authentication and push notifications
* Riverpod + GoRouter architecture
* E-commerce listings and subscription flows
* App Store & Play Store production releases

`Flutter` `Dart` `Riverpod` `GoRouter` `WebSockets` `Firebase` `REST`

---

### 🔁 [SwipeLoop](https://www.swipeloop.app/)

**Founder & Engineer**

AI-native SaaS for generating social content and visual experiences.

I designed and built the product end-to-end, including authentication, subscriptions, credit billing, storage, analytics and the AI generation infrastructure.

The generation system uses an **asynchronous multi-agent pipeline** with specialized agents for research, strategy, narrative, copy, QA and visual direction.

`Next.js` `React` `TypeScript` `PostgreSQL` `Supabase` `OpenRouter` `PostHog` `Vercel`

---

### 🛒 Headless Commerce

**Independent Frontend / Full-Stack Developer**

I build custom e-commerce products where the storefront is completely decoupled from the commerce engine.

Projects include **Florida Home Furniture** and **Easy Home Appliance**, using custom Next.js storefronts connected to Vendure.

* Custom storefront architecture
* 1,000+ product migrations
* Checkout and payment integrations
* Scraping and catalog automation
* Custom business logic
* Railway / Vercel infrastructure

`Next.js` `TypeScript` `Vendure` `PostgreSQL` `Stripe` `Railway` `Vercel`
